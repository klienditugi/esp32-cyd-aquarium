CYD Pixel Aquarium

Turn your Cheap Yellow Display into a living pixel aquarium. Install firmware directly from your browser.

ESP32-2432S028R

For the standard 2.8-inch ESP32 Cheap Yellow Display. Other CYD variants are not supported by this build.

Use desktop Chrome or Edge with USB serial support. This installer requires HTTPS.
  1. Connect the CYD with a USB data cable.
  2. Close programs using its serial port.
  3. Click Install Aquarium and choose the correct port.
  4. Follow the installer prompts, then restart your device if needed.

Flashing can erase the board's existing firmware and saved data.
